# 005. AiReport 저장을 INSERT IGNORE 로 멱등화한다

- 날짜: 2026-07-02
- 상태: 채택

## 배경
AI 리포트는 RabbitMQ 이벤트로 도착한다. 메시지 재전달이나 중복 발행이 생기면 같은 리포트를 두 번 저장하려 하고, 기존 구현은 여기서 실패했다.

## 결정
`AiReport` 저장을 `INSERT IGNORE` 로 바꿔 중복 키를 조용히 무시한다.

## 근거
- 메시지 큐는 at-least-once 전달이라 중복 도착을 애초에 막을 수 없다. 받는 쪽이 멱등해야 한다
- 먼저 조회하고 없으면 넣는 방식은 동시 도착 시 경합에 그대로 노출된다. DB 의 유니크 제약이 판정하게 두는 쪽이 정확하다

## 결과/영향
- 중복 메시지가 와도 저장이 실패하지 않는다
- 먼저 들어온 리포트가 남는다. 나중 메시지의 내용이 더 최신이어도 덮어쓰지 않는다
