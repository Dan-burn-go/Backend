# 006. LLM 429 재시도 대기를 쿼터 회복 시간에 맞춘다

- 날짜: 2026-07-01
- 상태: 채택

## 배경
외부 LLM 이 429 를 반환할 때 지수 백오프 base_delay 가 6초여서 대기가 6→12→24초였다. 쿼터 회복 전에 재시도가 끝나 결국 실패했다.

## 결정
base_delay 를 15초로 올려 대기를 15→30→60초로 만든다.

## 근거
- 쿼터 회복에 수 분이 걸리는데 24초 안에 재시도를 끝내면 회복을 기다리지 못한다
- 재시도로 못 살린 메시지는 DLQ 가 받는다. 백오프는 DLQ 로 가는 양을 줄이는 1차 방어선이다

## 결과/영향
- 성공하는 재시도의 지연이 늘어난다. 분석 리포트가 최대 1분여 늦게 도착할 수 있다
- 호출 제한 상황에서 불필요한 호출이 줄어든다
