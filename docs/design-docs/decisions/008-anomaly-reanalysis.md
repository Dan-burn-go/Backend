# 008. 혼잡이 지속되면 1시간 주기로 anomaly 재분석한다

- 날짜: 2026-06-06
- 상태: 채택

## 배경
상승 엣지에서만 분석하면(`001`) 혼잡이 길게 이어질 때 첫 분석 이후 갱신이 없다. 원인이 바뀌어도 리포트는 그대로다.

## 결정
혼잡 지속 시 1시간 주기로 anomaly 재분석을 수행한다. anomaly 판정 임계는 ratio 1.3, delta 2000 이다(초기 1.5 / 3000 에서 하향).

TTL 설정값이 0 이하로 잘못 들어오면 기본 60분으로 되돌리는 하한 가드를 둔다.

## 근거
- 임계가 1.5 / 3000 일 때 실제 이상 상황을 놓쳤다
- anomaly 큐는 `max_size=1` 로 즉시 처리한다. 배치로 모으면 이상 상황 대응이 늦다
- 잘못된 TTL 설정이 캐시를 무력화하는 사고를 막으려면 코드 쪽 하한이 필요하다

## 결과/영향
- 혼잡 지속 구간에서 LLM 호출이 늘어난다. 1시간 주기가 그 상한이다
